# Web Crawler with JavaFX

This project is a **simple web crawler** application built using **JavaFX** for the graphical user interface. It was developed as a learning project with documentation and interface primarily written in **Persian (Farsi)**.

## Features

* User-friendly GUI using JavaFX
* Accepts a starting URL from the user
* Crawls web pages and extracts hyperlinks
* Displays the discovered links in the interface

## Requirements

To run this project, you need:

* Java JDK 11 or higher
* JavaFX SDK (you can add it via your IDE like IntelliJ IDEA)

## How to Run

1. Clone or download the repository:

   ```bash
   git clone https://github.com/porya-gohary/WebCrawler
   ```

2. Open the project in an IDE (e.g., IntelliJ IDEA or Eclipse).

3. Ensure JavaFX is correctly configured with your project.

4. Run the program, enter a URL, and click the "Start Crawling" button.
